# SEO Оптимизация сайта

Этот документ описывает реализованные SEO улучшения для сайта "Ваш проект - Проектирование домов".

## Реализованные улучшения

### 1. Динамические мета-теги

Создан компонент `SEO.tsx`, который динамически управляет мета-тегами для каждой страницы:

- **Title** - уникальный для каждой страницы
- **Description** - оптимизированное описание для поисковых систем
- **Keywords** - релевантные ключевые слова
- **Canonical URLs** - предотвращение дублирования контента
- **Open Graph теги** - для социальных сетей (Facebook, VK и др.)
- **Twitter Card теги** - для Twitter

### 2. Структурированные данные (JSON-LD)

Добавлены структурированные данные Schema.org для улучшения понимания сайта поисковыми системами:

#### Главная страница:
- **Organization** - информация об организации с адресом (Могилев, Могилевская область, Беларусь)
- **LocalBusiness** - локальная бизнес-информация для улучшения локального SEO
- **WebSite** - информация о сайте с поисковой функцией

#### Страница каталога проектов:
- **CollectionPage** - страница коллекции проектов
- **ItemList** - список проектов
- **BreadcrumbList** - навигационные цепочки

#### Страница проекта:
- **CreativeWork** - информация о конкретном проекте
- **BreadcrumbList** - навигационные цепочки

### 3. Sitemap.xml

Создан плагин Vite (`vite-plugin-sitemap.ts`), который автоматически генерирует `sitemap.xml` при сборке проекта.

Sitemap включает:
- Главную страницу (приоритет 1.0)
- Страницу каталога проектов (приоритет 0.9)
- Все страницы проектов (приоритет 0.8)

### 4. Robots.txt

Обновлен файл `robots.txt` с добавлением ссылки на sitemap.

**Важно**: URL сайта настроен на `https://vashproekt.by`. Если нужно изменить, обновите в `robots.txt` и в переменной окружения `VITE_SITE_URL`.

### 5. Локальное SEO

Добавлена информация о локации для улучшения локального поиска:

- **Географические мета-теги** - geo.region, geo.placename, geo.position
- **LocalBusiness Schema** - полная информация о бизнесе с адресом
- **Уточнение локации** - Могилев, Могилевская область, Могилевский район, Беларусь
- **Ключевые слова с локацией** - все ключевые слова содержат упоминание Могилева и Могилевской области

### 6. Оптимизация изображений

- Все изображения имеют атрибут `alt` с описательным текстом
- Используется компонент `WatermarkImage` для защиты изображений

## Настройка перед деплоем

### 1. URL сайта

URL сайта настроен на `https://vashproekt.by` в:
- `vite-plugin-sitemap.ts` (по умолчанию)
- `public/robots.txt`

Если нужно изменить URL, обновите эти файлы или используйте переменную окружения:
```bash
VITE_SITE_URL=https://vashproekt.by npm run build
```

### 2. Проверка robots.txt

Файл `public/robots.txt` содержит правильную ссылку на sitemap:
```
Sitemap: https://vashproekt.by/sitemap.xml
```

### 3. Проверьте мета-теги

После деплоя проверьте мета-теги с помощью:
- [Google Rich Results Test](https://search.google.com/test/rich-results)
- [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)
- [Twitter Card Validator](https://cards-dev.twitter.com/validator)

## Рекомендации для дальнейшего улучшения

### 1. Добавьте больше структурированных данных

- **LocalBusiness** - если есть физический офис
- **Review** - отзывы клиентов
- **FAQPage** - если есть раздел с вопросами

### 2. Оптимизация производительности

- Используйте lazy loading для изображений
- Оптимизируйте размер изображений (WebP формат)
- Минифицируйте CSS и JavaScript

### 3. Контентная оптимизация

- Добавьте больше уникального контента на страницы проектов
- Создайте блог с полезными статьями о проектировании
- Добавьте раздел с часто задаваемыми вопросами

### 4. Внешние ссылки

- Получите обратные ссылки с авторитетных сайтов
- Добавьте сайт в каталоги архитектурных проектов
- Используйте социальные сети для продвижения

### 5. Технические улучшения

- Настройте HTTPS (обязательно для хорошего SEO)
- Убедитесь, что сайт быстро загружается (цель: < 3 секунды)
- Проверьте мобильную версию сайта (Mobile-Friendly Test)

## Мониторинг SEO

Рекомендуется настроить:

1. **Google Search Console** - для отслеживания индексации и поисковых запросов
2. **Google Analytics** - для анализа трафика
3. **Яндекс.Вебмастер** - для российского рынка
