# Инструкция по развертыванию проекта

## Подготовка к деплою

### 1. Установка зависимостей

Убедитесь, что все зависимости установлены:

```bash
npm install
```

### 2. Сборка проекта

Для создания production-версии выполните:

```bash
npm run build
```

После успешной сборки все файлы будут находиться в папке `dist/`.

### 3. Проверка сборки локально

Перед загрузкой на хостинг можно проверить сборку локально:

```bash
npm run preview
```

Это запустит локальный сервер для просмотра собранного проекта.

## Развертывание на хостинг

### Статический хостинг (рекомендуется)

Проект готов для развертывания на любом статическом хостинге:

- **Netlify**: Перетащите папку `dist/` в Netlify или подключите репозиторий
- **Vercel**: Подключите репозиторий, Vercel автоматически определит Vite
- **GitHub Pages**: Загрузите содержимое папки `dist/` в репозиторий
- **Обычный хостинг**: Загрузите все файлы из папки `dist/` на сервер через FTP/SFTP

### Важные файлы для загрузки

Из папки `dist/` нужно загрузить:
- Все файлы `.html`
- Все файлы `.js` из папки `assets/`
- Все файлы `.css` из папки `assets/`
- Все изображения и другие статические ресурсы

### Настройка сервера

Если используете обычный веб-сервер (Apache/Nginx), убедитесь, что настроен правильный routing для SPA:

**Apache (.htaccess в корне dist/):**
```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
```

**Nginx:**
```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

## Структура после сборки

```
dist/
├── index.html
├── assets/
│   ├── index-[hash].js
│   ├── index-[hash].css
│   └── [другие ресурсы]
└── [статические файлы из public/]
```

## Переменные окружения

Если в проекте используются переменные окружения, создайте файл `.env.production` перед сборкой:

```env
VITE_API_URL=https://your-api-url.com
```

## Проверка после деплоя

После развертывания проверьте:
1. ✅ Главная страница загружается
2. ✅ Все изображения отображаются
3. ✅ Стили применяются корректно
4. ✅ Навигация работает (SPA routing)
5. ✅ Формы работают
6. ✅ Favicon отображается

## Поддержка

При возникновении проблем проверьте:
- Консоль браузера на наличие ошибок
- Логи сервера
- Правильность путей к ресурсам
- Настройки CORS (если используются внешние API)
